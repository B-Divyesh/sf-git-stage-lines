Plain-language policy

Keep repository data local

git-stage-lines does not send repository data over a network.

CLI

The executable works inside your local Git repository. It has no network calls.

Selectors contain repository-relative paths. Demo mode creates a separate temporary repository from bundled sample files.

Website

This static site makes same-origin requests. It uses no cookies, local storage, or session storage.

A service worker caches public site files for offline access. Clear this site’s browser data to remove the cache.

Contact

For questions, open an issue in the public repository (external).
