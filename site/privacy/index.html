Plain-language policy

Privacy, by absence.

git-stage-lines does not collect, transmit, or store personal data.

CLI

The executable works entirely inside your local Git repository. It makes no network requests, includes no telemetry, and does not inspect files beyond the paths you explicitly provide.

Website

This static documentation site uses no analytics, cookies, accounts, advertising, or third-party scripts. Its service worker stores public page assets in your browser cache solely for offline access; clearing site data removes them.

Contact

For questions, open an issue in the public repository.
